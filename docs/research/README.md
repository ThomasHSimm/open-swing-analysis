# Research archive

This directory preserves the evidence that shaped Open Swing Analysis:

- [`benchmarks/`](benchmarks/) contains executed package/repository evaluations,
  the consolidated review, reuse decisions, and reproduction instructions.
- [`literature/`](literature/) contains the evidence register, paper extractions,
  synthesis, and open gaps.
- [`background/`](background/) contains earlier landscape and deep-research reports.
- [`study-design/`](study-design/) preserves the preliminary golf-balance study
  protocol, measures, and analysis plan.
- [`legacy-site/`](legacy-site/) contains the former project landing-page source for
  historical context; the old Quarto deployment was not migrated.

Research notes may contain provisional conclusions. Current implementation decisions
belong in `docs/architecture/` and `docs/development/` and should cite the evidence
here rather than silently copying it.
